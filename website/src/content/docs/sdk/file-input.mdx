`FilePart` represents a document or video included in a message. The `mime_type` field describes its format, and `filename` provides a document name when one is needed.

The file contents can be supplied through `data` or referenced by a `url` that the provider can access. The SDK passes the contents through as provided, so they should be prepared in the format accepted by the model.

```ts
const response = await model.generate({
  messages: [
    {
      role: "user",
      content: [
        { type: "text", text: "Summarize the attached report." },
        {
          type: "file",
          mime_type: "application/pdf",
          url: "https://example.com/report.pdf",
          filename: "report.pdf",
        },
      ],
    },
  ],
});
```
